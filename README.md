# TechFix Android App

Java Android Studio coursework implementation for the NIBM Mobile Application Development brief.

## Included
- Customer home dashboard
- TechFix Colombo and Galle branches
- Repair service catalogue and prices
- Local SQLite storage
- Repair appointment booking
- Repair request tracking
- Repair history
- GPS nearest branch calculation
- Camera integration for device photos
- Free OpenStreetMap Nominatim web service demonstration
- Demo payment status flow
- Material 3 Android UI

## Free stack
- Java
- Android Studio
- SQLite
- Android LocationManager
- Android Camera Intent
- OpenStreetMap Nominatim
- AndroidX and Material Components

No paid API key is required for the included features.

## Run
Open this repository in Android Studio as an existing Gradle project. Allow Android Studio to sync the Android Gradle Plugin dependencies. Run on an Android emulator or physical device.

The coursework requires GPS, web services, complex data handling, camera/image integration, and SQLite/offline functionality. The implementation includes these areas.

## Coursework alignment
The assessment brief asks for branch information, repair services, appointments, repair tracking, repair history, branch assignment, and payment handling. It also lists GPS, web services, complex data models/adaptors, camera/image integration, and SQLite as possible Android deliverables. The app implements a lightweight version of each requested area suitable for a fast coursework prototype.
